# Согласованная тройка голосов ElevenLabs

Для утверждения подготовлен единый спокойный женский профиль ElevenLabs на трёх языках:

- казахский — Sarah, `eleven_v3`;
- русский — Sarah, `eleven_v3`;
- английский — Sarah, `eleven_v3`.

Все три версии используют один и тот же ElevenLabs `voice_id`, поэтому тембр действительно совпадает.

Все три образца произносят эквивалентное сообщение для талона `D-428` и приведены к общему формату: MP3, 24 кГц, mono, целевая громкость −18 LUFS.

Собрать комплект повторно:

```powershell
npm run tts:trio
```

Страница сравнения после сборки:

```text
client/public/audio/seo/matched-voices/index.html
```

При запущенном проекте она доступна по адресу `/audio/seo/matched-voices/index.html`.
