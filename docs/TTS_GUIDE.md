# Озвучка СЭО

Голосовой пакет `ANNOUNCE_SOON` собирает реплику из статических фрагментов, латинского префикса `A`–`D` и количественного числительного от 1 до 1000.

Точные имена модели и голосов, тексты, порядок сборки и параметры звука хранятся в `client/public/audio/seo/voice-manifest.json`. Ведущие нули не произносятся. Во всех трёх языках префиксы произносятся одинаково: `A` — «эй», `B` — «би», `C` — «си», `D` — «ди».

Каждый префикс, числовой сегмент и статическая часть реплики хранятся отдельным WAV-файлом. Внутри одного языка все фрагменты генерируются одним утверждённым голосом.

## Тексты

- русский текст зафиксирован как утверждённый;
- казахский и английский переводы помечены как `ready_for_acceptance`;
- выбранные женские голоса: `en-US-AvaMultilingualNeural` для русского, `kk-KZ-AigulNeural` для казахского и `en-US-EmmaNeural` для английского.
- казахская формулировка: «{N} нөмірлі қызмет алушы, сізді жақын арада шақырады. Күту аймағына өтіңіз»;

## Генерация

Нужны Node.js 20+, Python 3, `ffmpeg` в `PATH` и пакет `edge-tts`. API-ключ не требуется.

```powershell
npm run tts:install
npm run tts:dry-run
npm run tts:generate
```

Генератор пропускает уже существующие файлы. Для обновления всего пакета после смены голоса:

```powershell
npm run tts:generate -- --force
```

Можно перегенерировать только один язык:

```powershell
npm run tts:generate -- --language kk --force
```

## Предпрослушивание

Предварительные MP3 для талонов `A-015` и `B-016` лежат в `client/public/audio/seo/previews/`. Они созданы цельными через Microsoft Edge TTS только для сравнения голосов и не являются финальным пакетом. Имена голосов и точные тексты записаны в `previews/preview-manifest.json`.

После генерации сегментов собрать тестовую реплику:

```powershell
npm run tts:compose -- --language ru --prefix A --number 15
npm run tts:compose -- --language kk --prefix B --number 207
npm run tts:compose -- --language en --prefix C --number 999
```

Готовые примеры появятся в `client/public/audio/seo/previews/`. При склейке используется короткий crossfade, а все фрагменты приводятся к одинаковой частоте, канальности и громкости.

При запущенном frontend страница с тремя финальными примерами доступна по адресу `http://localhost:5174/audio/seo/preview.html`.

Отдельная автономная страница `client/public/audio/seo/voice-variants/index.html` содержит по 10 женских вариантов для русского, казахского и английского. Она открывается двойным кликом без запуска frontend.

Для казахского дополнительно подготовлены отдельные женские голоса Silero TTS: `kaz_zhadyra`, `kaz_zhazira`, `kaz_aidana`, `kaz_aisha` и `kaz_danara`. Сгенерировать их повторно можно через Docker:

```powershell
npm run tts:kk:silero
```

Страница сравнения доступна по адресу `http://localhost:5174/audio/seo/silero-kazakh/index.html`. `kaz_zhadyra` и `kaz_zhazira` из модели `v5_cis_base_nostress` помечены как кандидаты для интеграции; остальные три голоса сохранены только для сравнения до отдельной проверки лицензии.

Перед вводом в эксплуатацию пользователю нужно сообщить, что озвучка сгенерирована ИИ.
