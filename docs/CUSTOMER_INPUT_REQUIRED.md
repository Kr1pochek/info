# Материалы заказчика для обновлённого ТЗ

Программные поля и интерфейсы подготовлены. Для финального наполнения требуются:

1. Подтверждение заказчиком памятки о правах и обязанностях налогоплательщика, подготовленной на двух языках по статье 36 Налогового кодекса № 214-VIII.
2. Актуальные ФИО и фотография уполномоченного по этике. До подтверждения используется нейтральная должностная карточка и телефон, опубликованный ДГД Алматы.
3. Календарь ежемесячной, квартальной и полугодовой отчётности, а также сроков уплаты налогов.
4. На каждый день эфира: фотография, ФИО, категория и перечень услуг онлайн‑специалиста на двух языках.
5. Дополнительные QR‑коды, кроме уже подготовленных официальных ссылок на `kgd.gov.kz` и `egov.kz`, если заказчик утвердит другие ресурсы.
6. Данные заказчика, упомянутые в ТЗ для ОВ‑8—ОВ‑13.
7. API/стенд NOMAD для повышенной громкости табло, статуса «Лицо с инвалидностью» и уведомления назначенного специалиста.
8. Подтверждение порядка последующей актуализации карточек услуг с `kgd.gov.kz`.
9. Утверждённые назначение, целевая категория, состав услуг и зона обслуживания временно скрытого пакета «Почётный».
10. Согласованный фирменный стиль, цветовая схема и типографика интерфейсов.
11. Утверждённый перечень фраз, голоса и язык озвучивания по умолчанию.
12. Подтверждение форм-фактора подсистемы 1: вертикальный киоск либо горизонтальный сенсорный стол.

Компьютер Lenovo и физическое подключение ТВ‑1/ТВ‑2 исключены из нашей зоны ответственности по отдельному указанию заказчика.
