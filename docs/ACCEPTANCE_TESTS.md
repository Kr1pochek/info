# Приёмочные проверки

## Автоматическая проверка

Из корня проекта:

```powershell
npm run verify
```

Команда выполняет lint, production-сборку, API-тесты и Chromium-проверку интерфейса. Responsive-тест охватывает `/kiosk`, `/packages`, пакет «Прогресс», `/news` и `/admin/login` в трёх режимах:

- Full HD 1920×1080, 100%;
- QHD 2048×1152, 125%;
- 4K 2560×1440, 150%.

Тест проверяет HTTP 200, отсутствие ошибок JavaScript, горизонтального переполнения, активные CSS-анимации прогресс-бара и бегущей строки, вычисляемые цвета высококонтрастного режима внутреннего инфокиоска, локализованную ошибку входа, успешную авторизацию, сохранение казахского языка в защищённых разделах и наличие всех настроек озвучивания. API-тест дополнительно изменяет и восстанавливает параметры озвучивания, подтверждая полный цикл сохранения.
