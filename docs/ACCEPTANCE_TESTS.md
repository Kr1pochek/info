# Приёмочные проверки

## Автоматическая проверка

Из корня проекта:

```powershell
npm run verify
```

Команда выполняет lint, production-сборку, API-тесты и Chromium-проверку интерфейса. Responsive-тест охватывает `/kiosk`, `/packages`, пакет «Прогресс», обе информационные карточки, `/news` и `/admin/login` в четырёх режимах:

- Full HD 1920×1080, 100%;
- вертикальный Full HD 1080×1920, 100%;
- QHD 2048×1152, 125%;
- 4K 2560×1440, 150%.

Тест проверяет HTTP 200, отсутствие ошибок JavaScript, горизонтального переполнения, активные CSS-анимации прогресс-бара и бегущей строки, отсутствие кнопки режима зрения в новостной ленте, локализованную ошибку входа, успешную авторизацию и сохранение казахского языка в защищённых разделах.

## Что требует стенда заказчика

Физическое подключение ТВ‑1/ТВ‑2 исключено из нашей зоны ответственности и проверяется на оборудовании заказчика.
